# Food Delivery Time Prediction System

A regression model that predicts food delivery time (in minutes) based on distance, item count, traffic level, and preparation time. Built as part of my Machine Learning Internship at Learn Depth.

## Results
- **Best model:** Linear Regression
- **MAE:** 4.6 minutes
- **R²:** 0.94

## Files
- `delivery_time_prediction.ipynb` — full notebook (data cleaning, model training, evaluation)
- `delivery_time.csv` — dataset
- `delivery_time_report.pdf` — 2-page project summary report

## Tools
Python, pandas, NumPy, scikit-learn, matplotlib, seaborn
